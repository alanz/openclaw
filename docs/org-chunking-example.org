** Background
*** Historical Context

Memory systems have evolved significantly. Early systems used simple keyword matching,
while modern approaches leverage neural embeddings for semantic search.

#+BEGIN_QUOTE

*** Current Approaches

Modern systems typically use:
1. Fixed-size chunking (simple but breaks context)
2. Sentence-based chunking (better but misses structure)
3. Structure-aware chunking (optimal for hierarchical content)

** Implementation Details
*** Vector Embeddings

The core of semantic search relies on converting text to dense vectors.

#+BEGIN_SRC python
def generate_embedding(text: str) -> np.ndarray:
    """Generate embedding for text chunk."""
    # Tokenize and encode
    tokens = tokenizer.encode(text)
    # Generate embedding
    embedding = model.encode(tokens)
    return embedding
#+END_SRC

Key considerations:
- Token limits (e.g., 512, 2048)
